# 老张的个人博客

一个基于 GitHub Pages 搭建的纯静态个人博客，采用暗黑风格设计，简洁、轻量、易维护，适合记录日常、旅行随笔和技术笔记。

## 项目介绍

本博客是纯静态架构，无需服务器、无需后台，直接托管在 GitHub Pages 上，加载速度快、稳定性高。整体采用暗黑风格，视觉舒适，适配各种设备，包含文章分页、摘要截断、固定布局等实用功能，适合个人日常记录和分享。

## 技术栈

- 前端：HTML5 + CSS3 + 原生 JavaScript
- 部署：GitHub Pages
- 风格：暗黑系响应式设计（适配移动端、PC 端）

## 核心功能

1.  文章展示：卡片式布局，标题、日期、作者、摘要清晰呈现
2.  分页功能：每页固定显示 5 篇文章，支持「上一页/下一页」切换
3.  摘要截断：文章摘要自动限制 30 字，超出部分显示「…」（JS 自动实现）
4.  固定布局：日期和作者固定在卡片右上角（水平排列），阅读更多按钮固定在卡片右下角
5.  响应式设计：适配不同屏幕尺寸，手机、电脑端均有良好体验
6.  暗黑风格：整体采用深色配色，保护视力，视觉简洁高级
