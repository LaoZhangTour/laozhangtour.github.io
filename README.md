# 老张的个人博客
一个基于 GitHub Pages 搭建的纯静态个人博客，暗黑风格、轻量简洁、无后端、免服务器，适合日常随笔、生活记录、技术笔记托管。

## 项目介绍
本项目为**纯 HTML + CSS + 原生 JS** 静态博客，托管于 GitHub Pages，访问稳定、加载快速。
采用卡片式文章布局，自带**自动分页、摘要30字自动省略、右上角日期作者水平排列、右下角阅读更多**等功能，布局固定不乱飘，适配电脑与移动端。

## 技术栈
- 前端：HTML5 + CSS3 + 原生 JavaScript
- 部署平台：GitHub Pages
- 设计风格：深色暗黑极简风

## 核心功能
- 文章卡片布局：标题、日期、作者、摘要规整展示
- 智能分页：每页固定5篇，自动显示/隐藏上一页、下一页
- 摘要处理：JS 自动限制30字，超出自动加 `…`
- 固定定位：日期+作者水平排布固定卡片右上角，阅读更多固定右下角
- 暗黑主题：配色舒适，长期浏览不伤眼
- 无需后台：静态文件直接部署，零依赖、零配置
