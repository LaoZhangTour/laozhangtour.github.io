# 老张头的个人博客
一个基于 GitHub Pages 搭建的纯静态个人博客，暗黑风格、轻量简洁、无后端、免服务器，适合日常随笔、生活记录、技术笔记托管。

## 项目介绍
基于 GitHub Pages 搭建的暗黑风格静态个人博客，采用原生 HTML + CSS + JavaScript 开发，无后端、轻量免配置，适配电脑与移动端。
整体代码结构规范、样式统一收拢管理，拥有独立作者简介页、文章卡片布局、自动分页、摘要智能截断等完整功能，适合用来记录生活随笔、旅行日常与技术笔记。

## 技术栈
- 前端：HTML5 + CSS3 + 原生 JavaScript
- 部署平台：GitHub Pages
- 图标支持：Font Awesome 在线图标库
- 设计风格：极简暗黑主题

## 核心功能
- 首页卡片式文章布局，右上角展示日期与作者昵称
- JS 自动摘要处理，文字超出 30 字自动添加省略号
- 文章智能分页，自动控制每页数量、动态显隐上下页按钮
- 首页作者姓名超链接跳转简介页，鼠标悬浮变色、无下划线
- 独立作者简介页，身份证式左右分块对齐布局
- 简介页左侧头像下方放置圆形社交图标（QQ / 微博 / 邮箱）
- 全站统一圆角卡片、悬浮过渡动画、配色风格一致
